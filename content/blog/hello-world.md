This is a test post. You can write blog posts in **Markdown** — just create a new `.md` file in `content/blog/` and it will show up here.

## How to write a new post

1. Create a file like `content/blog/my-post.md`
2. Add frontmatter at the top:

```yaml
---
title: "My Post Title"
date: 2026-03-22
summary: "A short description that appears on the blog list."
---
```

3. Write your content in Markdown below the frontmatter
4. Run `hugo server` to preview, then `hugo` to build

That's it. No frameworks, no build tools, no dependencies. Just words.
